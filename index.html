Customer segmentation with SQL

Customers scored on recency, frequency and monetary value (RFM), then grouped into segments. Illustrative figures.

WITH rfm AS (
  SELECT customer_id,
         DATEDIFF(day, MAX(order_date), GETDATE()) AS recency,
         COUNT(*)    AS frequency,
         SUM(amount) AS monetary
  FROM orders
  GROUP BY customer_id
)
SELECT customer_id,
       NTILE(5) OVER (ORDER BY recency DESC) AS r,
       NTILE(5) OVER (ORDER BY frequency)    AS f,
       NTILE(5) OVER (ORDER BY monetary)     AS m
FROM rfm;

Data cleaning pipeline

A repeatable Python script that turns a raw export into a clean file and reports what it fixed.

import pandas as pd

df = pd.read_csv("raw_orders.csv")
df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")
df = df.drop_duplicates(subset="order_id")
df["order_date"] = pd.to_datetime(df["order_date"], errors="coerce")
df["amount"] = pd.to_numeric(df["amount"], errors="coerce")

issues = {
    "missing_dates": int(df["order_date"].isna().sum()),
    "missing_customers": int(df["customer_id"].isna().sum()),
    "negative_amounts": int((df["amount"] < 0).sum()),
}
clean = df.dropna(subset=["order_date", "customer_id"]).query("amount >= 0")
clean.to_csv("clean_orders.csv", index=False)
print(issues)
